# CT-clock
//
1) Project Summary- For this specific project I was tasked with creating a domestic and international clock for a website, in order to make it more accessible for the clients to see the time. The company wants to add this feature to their website to ensure it helps with time management and productivity. This task was given by the company to ensure that all applicants are capable of writing their own functional code as well as problem solving skills. The program fully lets the user interact with the menu and input a selected time that fits the company needs for all clients.

2) What did you do well?- I think for this problem I did a good job at breaking the project down into smaller pieces and overtime build it into one program. By breaking the program down into smaller parts I was able to focus on each part and ensure that they all worked alone respectively before I devised a plan to incorporate them all. Troubleshooting and bugging while coding also helped to correct a lot of the formatting errors I've encountered while trying to get my time to display as it should. Overall I was able to remain focused and fight through adversity to complete the task at hand, I think I did a great job at staying optimistic and continuing to build off my mistakes instead of letting them hold me back.

3) How could you make improvements to your code?- I think there's always room for improvement, personally I believe that my program can have more implementations that allows the clock the handle time changes on its own, by having the program run test periodically I can ensure the clock double checks the correct time. Another thing I can add is more structure to the program that can improve the input system to limit the amount of user difficulties that can be faced.  For example, someone could possibly enter a character that my program is unfamiliar with and it could crash my whole project. Which is exactly where I can start and add my improvements onto the over stability and strength of my code.

4) Which pieces of the code did you find most challenging to write, and how did you overcome this? What tools or resources are you adding to your support network?- The hardest part of this project was making sure that both clocks were showing the correct time simultaneously. It was an extensive process to make sure that I was diligent and kept the same logic throughout the same code. There were times when I would take a break and then come back and be completely lost because I would forget my place in my logic and lose my principles. To combat these challenges I faced, I had to make sure I had the assignment requirements pulled up next to me working as well as make sure I took breaks to test my code. Typing parts of the code and then ensuring that I was still following the same habit through testing, I was able to save myself a ton of time instead of having to go back and rewrite it all after tests. A couple resources that aided me in my assignment have been the compiler messages first and foremost because they allow me to know that there is something off in my code. Paying attention to the messages and trying to actually understand what they're saying gives you some form of indication where the problem may lie; it may not tell you exactly where it is, but with trial and error it can be found. I also used multiple tech forums to look up messages I was unaware of; most of them would give me good feedback on where to move further.

5) What skills from this project will be particularly transferable to other projects or course work?- The main thing I can carry to my other assignments and projects are to just break them down into smaller increments, testing each piece bit by bit can ultimately save a lot of time from confusion from the code and the logic. focusing on the specific requirements I was able to effectively test my code little by little and learn from trial and error. Debugging has also been a big help in making sure I'm aware of what some messages could mean and how running my program multiple times can actually be very useful.

6)  How did you make this program maintainable, readable, and adaptable?- I made this program easy and maintainable by doing them all one by one and perfecting the logic on them to the best of my abilities, from that point I was able to look at all the finish parts together and fit them in where I best see fit. From there, I was able to slowly build the program by each bit to ensure that each part had its own specific task while also providing simplier maintenance for later with the seperate functionlity codes.
